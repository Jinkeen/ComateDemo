# 界面设计规范

整体采用现代、克制、高端的金融科技风格。界面以浅灰背景和白色卡片为基础，通过黑色重点区域、蓝色交互状态、轻边框与大留白建立层级。页面应让用户在进入后的几秒内看懂核心数据与下一步操作。

## 核心原则

### 1. 用大面积黑色标明最重要的信息

每个页面只设置一个黑色核心区域，用于承载当前页面最重要的数据、结论或任务。黑色区域是页面的第一视觉锚点，应占据明显位置，并与周围白色卡片形成清晰对比。

黑色区域内最多包含：

1. 一个核心标题
2. 一个关键数字或关键结论
3. 一个辅助趋势信息
4. 一个主要操作按钮

避免在多个模块中重复使用大面积黑色。次级信息使用白色卡片、浅色背景或细线框表达，确保视觉焦点唯一。

### 2. 信息简洁明确，主动减少冗余

每个页面只围绕一个核心任务组织信息。首屏建议保留一个核心数据区、两至三个辅助模块和一个主要操作区。用户不需要立即处理的内容应收进二级页面、折叠区域或“查看全部”入口。

同一指标只展示一次。标题、说明、标签和数字之间避免重复表达。能够通过位置、颜色或组件形态说明的内容，不再增加解释文字。

单张卡片建议只回答一个问题，例如“我有多少资产”“本月支出如何”“最近发生了什么”。卡片内部控制在一个主指标和一组辅助信息以内。

## 视觉语言

页面背景使用暖灰或浅灰色，内容卡片以白色为主。核心色为黑色与电光蓝，绿色用于正向状态，橙红色用于支出、提醒或负向变化。辅助色只在必要位置出现。

卡片使用较大的统一圆角、浅色细边框和轻微阴影。模块划分优先依靠留白、背景差异和对齐关系。阴影保持柔和，避免产生厚重的悬浮感。

标题使用粗体深色文字，关键数字拥有最高字号。说明文字使用冷灰色，并保持足够对比度。页面最多设置三级文字层级。

## 布局与信息层级

桌面端采用顶部导航与主内容区结构。只有在确实需要跨模块切换时保留左侧栏。侧栏入口建议控制在五项以内，低频功能归入“更多”或设置页。

主内容区遵循以下阅读顺序：

1. 页面标题与必要筛选
2. 黑色核心信息区
3. 两至三个辅助数据模块
4. 最近记录或后续操作

每行优先放置一至三个模块。模块之间保持明显间距，卡片内部元素保持紧凑。避免将大量小卡片铺满页面。

## 数据展示

图表只保留与当前决策有关的数据。默认展示一个主要时间范围，并提供简洁切换。坐标、图例和提示信息应清晰，但只显示必要内容。

概览页最多保留一个主图表。其他趋势可使用迷你折线、进度条或简短百分比。交易列表默认显示三至五条记录，其余内容通过“查看全部”进入完整列表。

筛选项只展示高频条件。多个低频筛选集中放入一个筛选面板。表格列数应控制在用户能够快速横向扫描的范围内。

## 组件约束

主要按钮每个页面最多一个，使用蓝色或黑色。次要操作使用文字按钮或浅色按钮。状态标签采用低饱和浅底色，避免抢占关键数据的注意力。

图标以简洁线性图标为主，同一页面保持统一线宽。装饰图形、人物图片和营销横幅仅在有明确业务价值时使用。

## 页面验收标准

设计完成后需要确认：用户能否在三秒内找到最重要的信息；页面是否只有一个明确视觉焦点；每张卡片是否只承担一个目的；删除任意模块后是否仍能完成核心任务；是否存在重复指标、重复标题或低价值说明。

当界面看起来信息过多时，优先删除低频模块、合并重复指标、缩短说明文字，并将完整数据下沉到详情页。
