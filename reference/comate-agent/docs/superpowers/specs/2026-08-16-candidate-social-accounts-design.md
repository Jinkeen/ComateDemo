# 候选人自媒体账号设计

## 目标

只重构简历详情中的“自媒体账号”页签，按参考图展示多个账号卡片和可展开的账号内容详情。筛选页与单人简历页继续复用同一组件，使全部简历保持一致。

## 信息结构

页签内容包含：

1. 标题“自媒体账号”和一句影响力说明。
2. 双列账号卡片列表，共 8 个账号。每张卡片展示头像、账号名、平台标签、粉丝或账号数据，以及“查看账号”按钮。
3. 点击卡片后，卡片在当前列表中横跨整行展开详情；再次点击收起，点击其他卡片切换展开项。
4. 默认展开“智东西”。

## 账号详情

智东西详情参考第二张图片，通过代码渲染：

- 账号头像、账号名称、等级标识；
- 2.4 万粉丝、703 个视频、官方账号说明；
- 三条近期视频：缩略图、播放量、标题和发布时间。

其他账号展开时使用相同结构，展示对应账号简介和示例内容。

## 图片资产

从用户提供的两张参考图中裁切账号头像和智东西的三张视频缩略图，保存到 `public/assets/recruiting/social/`。账号名称、数据、按钮、标签和视频文字均使用真实 HTML 文本，不烘焙到图片中。

## 组件与同步

继续使用 `CandidateSocialAccounts` 作为唯一实现。`CandidateApprovalStage` 与 `CandidateResumeDetail` 已经共同引用该组件，因此无需分别维护账号内容。

## 响应式与可访问性

- 宽栏使用双列账号卡，展开详情横跨两列。
- 窄栏使用单列，详情在对应卡片下方展开。
- 账号卡片使用按钮语义并维护 `aria-expanded`。
- 外部账号链接在新标签页打开。
- 图片提供描述性替代文本。
