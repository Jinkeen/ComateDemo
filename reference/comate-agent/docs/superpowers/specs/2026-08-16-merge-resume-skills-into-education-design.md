# 合并简历技能与教育背景设计

## 目标

删除简历详情中的独立“技能标签”页签，并将原技能内容移入“教育背景”。简历筛选详情与单人简历详情保持一致。

## 页面变化

页签调整为：

- 工作经历
- 教育背景
- 项目经验
- 自媒体账号

“教育背景”内容分为两部分：

1. 原有院校、专业、学历和就读时间；
2. “专业技能”区域，按原有能力分类展示技能内容。

候选人资料顶部用于快速浏览的技能标签不变。

## 实现范围

- 修改 `CandidateApprovalStage` 的页签和教育背景分支。
- 修改 `CandidateResumeDetail` 的页签和教育背景分支。
- 更新静态演示中的相同页签与内容。
- 更新相关设计说明和测试。

## 验证

- 两个简历详情中均不再出现“技能标签”页签。
- 点击“教育背景”可同时看到学校和专业技能。
- 项目经验与自媒体账号交互保持不变。
