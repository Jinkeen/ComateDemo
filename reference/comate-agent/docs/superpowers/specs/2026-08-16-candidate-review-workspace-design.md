# 候选人样本评审工作区

## 目标

用户在职位摘要下方点击任一推荐候选人的“查看简历”后，保留顶部全局导航和左侧对话记录栏，将其余区域切换为参考图中的候选人样本评审工作区。用户通过三个判断按钮评估候选人，提交后自动进入下一位推荐候选人。

## 路由与壳层

- 单候选人评审使用 `/hire/role/[roleId]?view=screening&mode=review&candidate=[candidateId]`。
- “全部简历”继续使用 `/hire/role/[roleId]?view=screening&mode=all`。
- `mode=review` 时：
  - 保留 `ComateGlobalHeader`；
  - 保留左侧 `ConversationHistorySidebar`；
  - 隐藏原 `RecruitingContextRail`；
  - 主区域使用评审专用双栏布局；
  - 顶部导航高亮“简历筛选”。
- `mode=all` 时继续使用当前全屏简历筛选布局。

## 页面结构

### 左侧 AI 评审栏

- 显示“评审样本 1 / 3”与紫色进度线。
- 展示 AI 对候选人经历的中文概括。
- 展示中文提问：“你认为这位候选人是否适合该岗位？”
- 三个判断按钮：
  - “适合”
  - “待确认”
  - “不适合”
- 按钮下方的判断原因提示全部使用中文：
  - 适合：`符合当前候选人画像`
  - 待确认：`部分条件需要进一步核实`
  - 不适合：`不符合岗位关键要求`
- 显示中文追问：“请补充判断原因，AI 会据此调整后续筛选偏好。”
- 底部输入框沿用悬浮卡片视觉，宽度严格与左侧 AI 评审栏对齐。
- 用户选中判断并输入原因后可提交；提交后自动切换下一位候选人。

### 右侧简历详情

- 默认第一位使用本地虚构候选人林澈（`synthetic-1`）的数据。
- 顶部包含匿名头像、姓名、匹配状态、职位、公司、地区、经验、学历、年龄和技能标签。
- 包含“下载简历”和“联系候选人”操作。
- 主体展示工作经历、教育背景、项目经验、自媒体账号四个页签。教育背景内同时展示院校信息和专业技能。
- 右侧窄栏展示匹配度、联系方式、AI 推荐理由和附件。
- 工作经历及简介优先读取候选人数据；缺少的联系方式、附件和详细经历使用明确标注为虚构的本地演示数据。

## 候选人推进

- 推荐队列固定为当前推荐区的前三位候选人。
- 首次进入时根据 `candidate` 参数确定当前索引。
- 提交判断后：
  1. 在组件本地保存 `{ candidateId, verdict, evidence }`；
  2. 更新 URL 中的 `candidate` 参数；
  3. 自动显示下一位候选人的 AI 概括和简历详情；
  4. 更新“评审样本 N / 3”与进度线。
- 第三位提交后显示评审完成状态，提供：
  - “返回职位摘要”
  - “进入全部简历”

## 组件边界

- `CandidateReviewStage`：读取候选人参数、维护三人队列与评审结果、编排左右布局。
- `CandidateReviewPanel`：左侧中文 AI 交互、判断按钮、原因输入与提交。
- `CandidateResumeDetail`：右侧可复用简历详情。
- `candidate-match-factory`：将本地 `seedCandidates` 转换为 `CandidateMatch` 并按 ID 获取。
- `CandidateApprovalStage` 后续复用 `CandidateResumeDetail`，避免详情 UI 重复。

## 视觉规范

- 参考图中的浅灰页面背景、白色面板、12–16px 圆角和轻描边。
- 左侧评审栏约占主区 34%，右侧简历详情约占 66%。
- 主要操作使用黑色按钮，选中判断使用紫色描边或浅紫背景。
- 信息密度保持紧凑，正文与标签均使用现有 Comate 字体和颜色变量。
- 评审区不出现横向滚动；小屏时改为上下排列。
- 所有按钮最小点击高度 44px，支持键盘焦点和减少动画设置。

## 测试

- 推荐卡“查看简历”链接进入 `mode=review`。
- `candidate=synthetic-1` 渲染林澈及三个中文判断按钮。
- 未选择判断或未填写原因时提交不可用。
- 提交第一位后自动进入第二位并更新 URL 与进度。
- 第三位提交后显示完成状态。
- 评审模式保留顶部导航与左侧对话记录，隐藏原右侧进展栏。
- “全部简历”仍进入现有完整筛选页。

## 范围外

- 不持久化样本判断到数据库。
- 不调用真实 AI 或真实候选人数据源。
- 不发送真实消息、不下载真实简历。
