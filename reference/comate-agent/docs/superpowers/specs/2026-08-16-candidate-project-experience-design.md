# 候选人项目经验卡片设计

## 目标

仅升级林澈简历中的“项目经验”栏目，按参考图展示信息完整的项目卡片，并确保简历筛选页与单候选人评审页复用同一份内容。

## 页面结构

项目经验区显示“开源项目 2”和“商业项目 1”两个分组：

- `langgenius/dify`：项目图标、热门标记、英文简介、语言与仓库数据、GitHub 和官网链接、Dify README 预览图。
- `langgenius/langgenius`：项目图标、英文简介、语言与仓库数据、GitHub 和官网链接、LangGenius GitHub 组织页预览图。
- `星河智能客服平台`：项目图标、企业内部标记、中文产品说明、技术标签和产品界面预览。

卡片采用白底、细边框、圆角和适度留白。桌面宽度下使用“图标 + 内容 + 预览图”三栏结构；空间不足时隐藏或下移预览图，保证正文可读。

## 组件与数据

新增共享组件 `CandidateProjectExperience`，内部维护本次演示所需的三条项目数据。`CandidateApprovalStage` 和 `CandidateResumeDetail` 的“项目经验”分支均渲染该组件，不修改其他标签页。

用户提供的两张参考截图复制到项目静态资源目录，作为前两张开源项目卡片的预览图。商业项目使用项目现有或新增的本地产品预览资源；不依赖运行时外部图片服务。

## 交互与可访问性

- GitHub 与官网使用真实锚点并在新标签页打开。
- 预览图提供描述性替代文本。
- 卡片在悬停时仅做轻微边框和阴影反馈。
- 两个页面展示相同项目顺序、文字和链接。

## 验证

- 测试两个页面在切换到“项目经验”后均出现三个项目名称。
- 测试 Dify 与 LangGenius 的外部链接地址。
- 运行相关组件测试、TypeScript 和编辑文件诊断。
