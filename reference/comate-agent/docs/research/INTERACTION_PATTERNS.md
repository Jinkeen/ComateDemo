# Metix 公开 Demo：交互模式

1. **直接输入或示例启动**：职位自由文本是主入口；四个示例角色用于自动播放端到端情境。
2. **渐进式披露**：阶段按钮在前置状态完成前禁用；进度 25/50/75/100%。
3. **对话即表单**：Agent 先总结职位，再按缺失字段提出澄清问题；聊天记录是上下文与可解释性载体。
4. **标定而非一次性筛选**：样本候选人评级用于调节后续匹配排序。
5. **显式策略选择**：Manual 与 Automatic 并置比较，说明审批责任与触达行为差异。
6. **触达前关口**：手动模式将候选人放入“Waiting Approval”，按复选框选择后才出现 `Approve & contact`。
7. **候选人查看层**：候选摘要、匹配标签、职位/地点、技能 chips；详情层含经历、教育、技能、联系信息与推荐理由。
8. **安全复刻规则**：本地项目把所有真实副作用改为模拟状态变化与通知，不调用邮件、LinkedIn、日历、支付或认证。
